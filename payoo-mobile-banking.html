FinTech Project Details

Payoo Mobile Banking A mobile banking interface focused on clarity, security, and quick transactions.

The project recreates a banking-style user flow with a simple PIN-based entry experience, action cards, and transaction history designed for practical everyday use.

Live Project Client GitHub Repo

Stack

HTML5, CSS3, JavaScript, Tailwind, DaisyUI

Built as a client-side banking experience with polished visual flow.

Description

A responsive demo app that organizes add money, cash out, and send money interactions in one UI.

Challenges

Designing secure-feeling navigation and card layouts while preserving readability on phone-sized screens.

Future Plans

Add authentication flow, persistent transaction state, and analytics for spending patterns.
